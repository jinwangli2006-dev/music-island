# Music Island

An educational music app built in JavaScript with Code.org App Lab. It introduces music concepts and instruments through interactive screens with sound. Built as a class project with a classmate.

Try it on Code.org: https://studio.code.org/projects/applab/qh2yXkB_8q3sSwXODmvTeoG3HoSes4IoihY5h1eFQ6o

## Contents

- `app.js` - the app's code (Code.org App Lab JavaScript)
- `design.html` - the App Lab design-mode screen markup
- The audio and image files are the app's assets, referenced by name in the code

Note: the app runs in the Code.org App Lab environment, so the code uses App Lab functions like `onEvent`, `setScreen` and `playSound`.
